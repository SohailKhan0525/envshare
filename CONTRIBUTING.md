Contributing

Thank you for wanting to help improve this project. It is meant to stay
small, boring, and easy to trust, so contributions that keep that spirit
are especially welcome.

Ways to help, no coding required

  try the tool with a real, small team and report anything confusing
  improve the wording in the readme or these guide files if something is
  unclear
  suggest a feature by opening an issue describing the real situation it
  would help with

Ways to help with code

  pick something from the what is still missing section near the bottom
  of the readme
  open an issue first to describe what you plan to change, before
  spending time writing it, so effort is not wasted on something that
  might not fit
  keep changes small and focused, one idea per contribution, this makes
  them much easier to review and trust

A note on style

This project intentionally avoids typed symbols in its everyday commands
and in its explanations, favoring plain words a newcomer can follow
without prior experience. When adding new commands or documentation,
please try to keep that same plain, welcoming tone.

A note on security

Because this project handles real secrets for real teams, changes that
touch locking, unlocking, access checks, or anything else related to
safety should explain clearly, in the pull request itself, exactly what
changed and why it is still safe. When in doubt, open an issue to discuss
the idea first.
